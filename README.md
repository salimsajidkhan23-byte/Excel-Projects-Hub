## Retail Sales Analysis Using Excel

## Project Overview

This project analyzes retail sales data using Microsoft Excel. The analysis was performed using Excel formulas, Pivot Tables, Pivot Charts, and an interactive dashboard.

## Project Objective

The objective of this project is to analyze sales performance and identify important patterns in:

● Sales and revenue
● Product categories
● Branch/store performance
● Customer types
● Payment methods
● Monthly sales trends
● Quantity sold
● Average transaction value

## Tools Used

● Microsoft Excel
● Excel Formulas
● Pivot Tables
● Pivot Charts
● Slicers
● Excel Dashboard

## Dashboard

The dashboard provides an interactive overview of retail sales performance.

## Key KPIs

● Total Sales
● Total Quantity Sold
● Total Transactions
● Average Sales
● Average Rating

## Dashboard Analysis

● Sales by Product Category
● Monthly Sales Trend
● Sales by Branch
● Sales by Customer Type
● Sales by Payment Method
● Quantity Sold by Product Category

## Analysis Process

● Imported the raw dataset into Excel.
● Checked and cleaned the data.
● Created calculated columns where required.
● Created Pivot Tables for analysis.
● Created Pivot Charts from the Pivot Tables.
A dded slicers for interactive filtering.
Designed an interactive Excel dashboard.
Identified key business insights.
